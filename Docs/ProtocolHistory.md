# Protocol version history

One line per bump, newest first. When you bump `Session.ProtocolVersion`, add your line at the top
(`NNN: what changed on the wire`). The code keeps only the number, so parallel sessions don't conflict on a long comment.
Before bumping, `git fetch origin main` and take main's number + 1, so two sessions don't ship the same number.
- 300: breach rooms: a breach wave adds a free Stash (`ExpansionRoom.Surprise` 6 = `SurpriseShape.Stash`) behind each remaining breach; no new fields (Docs/BreachRooms.md)

- 299: gold instead of a card: `Msg.Pick` with index 255 takes gold instead of an offered card (level-up offers only); `ShopAction.Remove` (value 2) is now `Sell` (pays half the shelf price instead of costing 75).
- 298: Out of Ammo reworked: the player snapshot carries `Player.KnifeMove` and `KnifeSeq` (bytes, after `AmmoSeq`); `AmmoMove` is now the rifle arms' move 1-4
- 297: Quick Play: the lobby message carries `QuickMode` (bool, after `HuntBoss`); `Msg.Start` carries, after the start wave, a Quick Play flag and (when set) its boss order (count byte + one `EnemyType` byte each).
- 296: new `EnemyType.Thug` and `EnemyType.Shiv` (the Warden's prisoner reskins of the Brute and Lunger; at the end of the enum).
- 295: Gas Grenadier overhand lob: new `FxKind.GasLob` (at the end of the enum; Pos = landing spot, Pos2 = (grenadier id, flight s), Pos2.Y = -1 for the release cue); the grenadier's `Winding` now covers its 1.07 s wind-up.
- 294: Out of Ammo (`WeaponId.OutOfAmmo`, the Twin Rifle's second variant, pick 4): the player snapshot carries `AmmoMove`, `AmmoSeq`, `SwatSeqL`, `SwatSeqR` (bytes), `SwatAngL`, `SwatAngR`, `AmmoSpin` (floats) after `TwinLock`; `Msg.WeaponDash` kind `DashSpin` (27)

- 292: built rooms of every size grow side walls (small rooms and narrow strips too; derived from the map, so both ends must build the same walls).
- 291: Black Market: `ShopAction.BuyBuild`, the player snapshot carries `Player.Stash` (a byte per `BuildKind`, after `ShelfSold`), `Msg.PlaceBuild`, `Msg.ExpandState` carries the placed traps (after the portal pairs); a portal pair is built from the stash (no vectors, no vote)
