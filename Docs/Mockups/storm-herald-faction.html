The Tempest

The Storm Herald's faction, the same size as the Warden's: 8 enemies. Each one previews a single attack of the boss, so by wave 40 you have already dodged every shape it throws. Shown with the Warden's slot each fills.

Members

Numbers are first guesses, copied from the Warden's and Infall's scale. Scenes loop; the teal dot is you.

Notes

  • Squads, the set piece and the 10-wave cycle are left for the next step (as the Infall's were).
  • Reuses boss code where it can: strikes (StrikeRadius, StrikeWarn), rods and arcs, the wind push and drift, ball lightning, the Conductor ring.
  • Wind-affected shots would use the Gale's drift on every enemy in this faction while no Herald is alive, so the lessons work on their own.
  • New EnemyType values go at the end, before None, with a protocol bump.
