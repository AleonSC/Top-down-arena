Between waves: Results, then Build, then Ready

Today the build window is a chip you open on the side while the Ready box is already counting. Here the break runs in order. Results first, then Build, then Ready, so the countdown only starts once building is done. Pick a look, then step through it (or click the on-screen keys).

Look
Step

A · Three tubes

Each step is its own tube in the same place. A step bar across the top shows where you are. Closest to today's Wave cleared box; Build gets the whole tube instead of a side window.

B · Tabbed tube

One tube with RESULTS / BUILD / READY tabs. Next and Back keys walk the order, but you can jump back to Build while waiting for a slow teammate. Fewest screens to learn.

C · Full-screen build

Results is a rack, Build takes the whole arena map with a tool column, Ready drops to a low strip so you see the rooms you just built behind it.

Skipped when it doesn't apply: Practice Range, Boss Hunts, the last wave, a full map and non-Expanding arenas go straight from Results to Ready (the step bar shows only two steps). Players: with Free building, each player builds on their own and presses Done; a teammate who is still building shows as "BUILDING" on the Ready tally. Auto-ready waits for Done.
