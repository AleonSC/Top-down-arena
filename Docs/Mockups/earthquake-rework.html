Earthquake rework

Today it is a flat slam: you and each minion hit everything within 140 px for 40 and slow it by half for 2 s. It works, but the minions only add circles. These four versions make the minions do something the player can see and plan around. Pick a tab to replay it. Below that are eight new abilities that summon something.

Each one is a cooldown ability in the same slot as Earthquake, Golem Wall and Guardian Spirit. Numbers are starting points for the sim tests, not tuned values.

Build notes

  • Reworking Earthquake in place changes no enum and no snapshot, so Session.ProtocolVersion stays put. Versions B and D add a few client-visible effects (a crack, a leap), which can ride on the existing FxKind messages or need a new value at the end of the enum, which does need a bump.
  • Every new ability below adds an AbilityId (and most a MinionKind) at the end, before None, and bumps the protocol version.
  • Version D needs minions to be told to move to a point and then return. The Golem Staff boulder and the Wolf Whistle already hand minions targets, so the hook exists; the new part is a short scripted leap that ignores collision.
  • The Bestiary and Armory pages are not touched by this. They will be out of date once any of these ships.
