The Infall

The Singularity's faction, the same size as the Warden's: 8 enemies, 4 squads, a set piece and a 10-wave Campaign cycle. Everything here is matter falling into the black hole, and each enemy previews one thing the boss tests.

Members

The Warden's slot each one fills is in brackets. Weight and first round copy the Warden's table in Approaches.cs.

Squads

Four squads and the wave-4 set piece, like Breakout / Yard / Patrol / Cell block and the Riot line.

Campaign cycle

One lesson per wave, building to the Singularity at wave 20.

Notes
