Aeroaegis 11 s cooldown · 56 px vortex · 3 s (4.5 s mastered) · blocks enemy bodies

Today: a spinning purple hexagon on the caster that reflects bullets. Enemies walk through it. Proposed: a wind vortex on you or an ally, chosen by cursor, that enemies cannot enter. They are swept sideways around the outside.

Beats

    What it fixes

    • Today the shield only helps against bullets. Melee enemies still reach the player, which is the main way a tank gets overwhelmed.
    • Targeting is readable: a dashed line and marker show who will be covered before the vortex lands.
    • The rim drains, so players can see how long the cover has left.
    • Enemies visibly bounce and slide off, which explains why they cannot get in.

    Build notes. Rules are a proposal: blocks enemy bodies only (bullets pass), 3 s, 4.5 s mastered. Keeps AbilityId.ArcaneAegis internally, so only the display name, PixelArt icon key and README change. The shield timer would sit on the targeted ally; the existing AegisT snapshot field probably covers it, so no protocol bump is expected. The "Current" view is approximate.
