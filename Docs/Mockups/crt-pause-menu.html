CRT Cabinet Menu

One cabinet with a header screen and an option screen, for both Pause and Settings. The cabinet stays on the left. Each option opens its own CRT window to its right; the window slides out on the first pick, and later picks rewrite its text. Settings is a menu like Pause, with each section in a window. Pick an opening under Opening and press Replay. Esc slides the menu away and back; arrow keys and Enter work on the pause list. Reduced effects (under Visual effects) really turns the glow, roll bar and flicker off.
