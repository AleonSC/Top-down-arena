Better Back, Ready & Start

Today all three are one flat tinted rounded box with a thin top highlight and a faint chip behind the icon. Start and Ready read as twins, and Back is a red square with an arrow. Four looks follow, each drawn at the in-game size with Ready? / Ready! and Start waiting / ready / practice, so you can compare the states, not just the paint. Colours stay inside the game's palette (blue, gold, red; Start turns green when it can start, and teal in Practice).

Option 1

Keycap

Good: closest to what you have, so it's the easiest to build: a vertical gradient, a darker lower lip, a gloss band and a round icon chip. Presses down 4 px on click.Good: Start (green) and Ready (blue, gold when ready) stop looking alike.Cost: a few extra Ui.Fill strips per button; no new textures.
