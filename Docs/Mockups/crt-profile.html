CRT Profile Cabinet

The profile as the same CRT cabinet as the pause menu: a header screen, a profile screen with rank badge and XP, tab keys, and a list of options. Each option opens in its own CRT window to the right; the window slides out on the first pick and later picks retype its text. In Look, hover a row to try a cosmetic on in the preview and the party card, and press Equip to keep it.
