Design notes

Always readable

Every cursor keeps a clear centre point and sits between about 20 and 40 px wide, so none hides enemies or bullets. Laser Dot is the smallest and Target Lock the busiest.

Rank ladder

Ranks are not chosen yet. Every rank from 2 to 79 already has a reward, so new cursors would go above 79 or share a rank with something existing.

Visual effects off

With Visual effects off, the animated ones (radar beam, sonar rings, chevron breathing, pixel colours, petal turn, target spin) fall back to a still version of the same shape and colour. In the game each also gets a small Corner pointer for menus, like the existing ten.
