Pixel sprites

Draw a figure as a grid of square cells so every cell can move on its own. The simulation is untouched; this is only how a thing is drawn. Move the mouse over the stage to aim the figure, then pick an effect.

Disintegrate, frame by frame

The killing hit came from the front, so the front breaks first. Each cell's delay, speed and sideways drift come from a hash of its own position, so every machine draws the same burst and nothing is stored.

At game size

A Tank is about 36 px across in the game. Here it is drawn 18 cells wide at 2 px a cell, then zoomed 4x without smoothing. This is how fine the grid really is on screen: the resting body is small, but the effect reads well.

What stays the same

  • The simulation. Positions, radii, hit boxes and the network snapshot don't change, so no protocol bump.
  • The hit core. The bright dot players aim for stays a separate vector dot over the pixels.
  • The settings. Visual effects off keeps the vector model; Reduced uses a plain fade, no scatter or flashes.

What to judge

  • Does the chunky grid sit well next to the glowing vector arena?
  • Free turning shimmers a little as cells re-sample; 8-way looks more like pixel art. Which?
  • Which effects do you want first?
