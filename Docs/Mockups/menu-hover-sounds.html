Hover sounds

The menu buttons turn into an old VHS tape while the mouse is over them. These are six ways that hover could sound. Move the mouse across the buttons in each card (sweep quickly to hear how it behaves when you skim the list), or press Play. Click a button to hear the click on top of the hover. On a phone, tap.

How it would be built

  • In MenuVhs.Draw the per-button State.Hover already flips on enter. Play the pick on the false → true edge only (not every frame), and the matching leave sound, if any, on true → false.
  • New Sfx.MenuHover (and Sfx.MenuClick for look-matched clicks) in SoundBank.cs, added at the end of the enum. Three pitch variants are baked and rotated so a sweep doesn't repeat the same sample.
  • Rate limit of about 40 ms between hover sounds, so skimming down the list stays a ripple and not a buzz. Falls under the existing menu sound volume. With Reduced effects (calm) the hover is quieter and the tape-specific layers are skipped.
  • Local only. No network message, so no protocol change.
