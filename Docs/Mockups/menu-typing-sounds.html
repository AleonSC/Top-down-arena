Main menu intro · title

Typing sounds

The menu title types out "CARTESIAN COLOSSEUM" on the CRT, 19 letters in 0.6 s, starting 0.95 s into the intro. These are four ways it could sound. Press Play on each. Use the slow speed to hear the single keys; the game speed is the real one. Sounds here are synthesised the same way as SoundBank.cs (tones and noise bursts, no clips).

How it would be built

  • In DrawMenuTitleText (MenuIntro.cs) the typed count crtTyped already steps once per letter. A new tick compares it with the last count and plays the pick once per new letter, so skipping the intro stops the sound with it.
  • New Sfx.TitleKey (and Sfx.TitleEnter for the last letter) in SoundBank.cs, added at the end of the enum. A few pitch variants are baked so repeated keys do not sound identical.
  • Falls under the existing menu sound volume. Quiet with reduced effects, where the title just fades. No network message, so no protocol change.
