Round Timeline

A dev-only bar over the game window. Pause, play, step a frame, fast forward, rewind and drag to any moment of the round. Try all three looks below: the stage is live, so press play and drag the bar.

A · Docked bar

Always the same place along the bottom edge, like a video player. Transport on the left, time and speed on the right. Smallest, most familiar.

B · Floating pill

Centred over the action so it covers the HUD less. Scrub bar on top, buttons under it. Reads best on small windows.

C · Wave lanes

Adds a wave strip so you can see where each wave and boss sits, and jump wave to wave. Most useful for balancing. Blue ticks are wave starts, red is a boss, amber is a player going down.

How it would work

Toggle with F1 then Timeline (or F6). While open: Space play or pause, , and . step one frame, [ and ] change speed (¼×, ½×, 1×, 2×, 4×), ← → jump 5 s, drag the bar to scrub.

Rewind works by saving a snapshot of the match every half second (the same data the host sends clients) and a short input log between snapshots, so scrubbing back restores the nearest snapshot and replays forward. Single player and host only; the bar is greyed out for clients. Snapshots are kept for the last 10 minutes. Restarting the round clears them. The network protocol does not change.
