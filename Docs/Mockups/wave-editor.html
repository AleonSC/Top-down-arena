Wave Editor

Three layouts for a full-screen wave editor, opened from the Practice tab's Edit waves. Each is filled with the same real wave: Warden Hunt, wave 6 (a Breakout rush, a Gas Grenadier pair, then the Riot line), so you can compare how each one shows what spawns, where, when, and the props on the floor.

All three save the same text file (shown in A), which the build turns into code for final builds.

  • The arena is the main thing. Spawn points are lettered pins on the edges or inside; props sit where they'll be in the match, drawn to the real 1600×900 scale.
  • Click a group and its spawn point lights up on the map, with an arrow for where its enemies head first.
  • Timing is numbers (starts at, one every), so it's precise, but you can't see the whole wave's rhythm at a glance.
  • The file panel shows exactly what Save writes, so you can always see what I'll get.

  • Timing is the main thing, laid out like a video editor: one track per group, a clip for when its enemies arrive.
  • Scrub or press Play and the small map shows the wave unfolding (who's in, from where), so you can feel pacing before testing.

Any option

Shared pieces

  • All three save the same .waves text file. For final builds a script turns it into code (like the Bestiary's data), so there are no loose files to go missing or out of sync in co-op.
  • Test plays the wave in the Practice Range with your party; saved waves can be assigned to a hunt, a boss's build-up or a path.
  • Mixing is fine: e.g. A's map with B's timeline strip under it.
