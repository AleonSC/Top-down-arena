Arc Lightning 2

Style A "Thunderhead" is built. Here are four different directions, none of them a jagged line with forks (A, B, C and D in the first round were all variations on that): E Skyfall drops strikes from above one after another, F Lichtenberg grows a fractal tree of lightning along the strip, G Circuit runs right-angle pulses and lights a pixel matrix (it matches the CRT menus), and H Ion Wave sends a ringing sine wave down the strip. Each covers charge, release, aftermath. Same numbers as the game (now a slight cone, 36 px wide at the staff to 90 px at the far end, 160 to 800 px long, 0.9 s to full, 40 damage, 0.4 s stun).

Notes for building it

  • Same hooks as style A: charge in DrawArcCharge, release in FxKind.ArcField (DrawArcFieldFx), which already carries the strip's start, end, half width and colour. No protocol change: every pattern below is seeded by where the strip went off, so all screens draw the same thing.
  • Only your own charge shows the strip preview (outline and markers), like today. Allies see the build-up at the caster only.
  • E needs the strike times (since = i * 0.28 / (n-1)), F a cached tree per cast (about 350 segments, built once), G a 16 px cell grid snapped to the strip, H nothing but a sine. All of them are cheap next to the glow pass.
  • The 0.4 s stun mark is a timer on each enemy hit, as in round one: scorch ring (E), violet crackle (F), square brackets (G), ripple (H).
  • Glows go in the additive glow pass; with Visual effects off the strip draws exactly as now.
  • Drawn at 0.55 of the game's scale so a full 800 px strip fits. If one is picked, the lobby preview gets the same look (as for style A).
