Host address bar, four ways

The "Host address" row from Join game, redone in the CRT style. Each one works: type in the field, press Connect (or Enter). Addresses that start with 127. or 192.168. connect; anything else times out so you can see the error state.

1 · Address screen and Connect keygreen
Host address

The closest to today's bar. The label and the address share one screen; the key sits to the right with a lamp that goes yellow while connecting and red on failure.

2 · Prompt lineamber

A terminal prompt instead of a label: one line, amber, with the caret in the field. Fits tight spaces such as the bottom of a box.

3 · Address, status and keygreen, three parts
Host address
READY

A small status screen between the address and the key says READY, CONNECTING... or NO ANSWER, so errors don't need a pop-up or a line elsewhere.

4 · Hybridblue key, CRT field only

Keeps the game's blue primary button so Connect still reads as the main action, and only the address field becomes a screen.
