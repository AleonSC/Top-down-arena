New run to lobby

Pressing New run on the Start a Run panel powers up the green console. The console opens outward until it fills the whole screen as the lobby, laid out like the game: back button and title, mode tabs, party list, Ready and Start on the left, and the loadout panel on the right. The background is a CRT screen with phosphor glow, scanlines, a slow roll bar and a faint flicker. The lobby controls keep their usual colours on top.
