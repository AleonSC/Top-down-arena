Main menu redesigns

Four directions for the main menu, each live: hover the buttons, and click Join game to open its address fields. Every design keeps the same choices (your name, Host, Join, Continue, Records, Settings, Quit) and the graph theme. The biggest common change: the host address and port only show when you join, so the menu leads with playing instead of a form.

Notes for building it

  • All in Menus.cs (DrawMenu, DrawMenuCardInside, DrawMenuSecondary); the axis, plot corners and lines are the GL helpers already there (DrawAxis, DrawPlotCorners).
  • The Continue line reads the newest save (savedRunsCount and the save list in SavesUi.cs): wave, classes, time played. With no saves it's hidden.
  • Your character (B and D) is the lobby's model drawing (DrawPlayer through UiModelAt) with your last class from the profile.
  • The move into the lobby (LobbyEnter.cs) slides the current card into the loadout; whichever design is picked needs that animation updated to start from its layout.
  • Any of these can sit after the plotted intro (the other mockup): the intro draws the title and axis, then the menu's pieces arrive in their own places.
