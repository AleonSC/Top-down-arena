More name effects

Eight new looks for your name wherever it is drawn: the lobby party card, the Hangout name plate, the tag over your head in a match and the results card. Everyone sees it. They sit beside the twelve name effects the ladder has today. Click one to put it on your name in the preview; the same name is shown at all four sizes. Small spots (the Hangout plate and the match tag) tone the motion down to colour and glow.

Effects

Where it shows. Everywhere a name is drawn through the name helper (DrawName in NameEffects.cs): the party card, the Hangout plate, the world tag over a player and the results strip. Chat and the pause list stay plain.

Readability. Letters stay solid and bright on every one. Hologram and Terminal are the riskiest: the scanlines are kept faint and the Terminal scramble lasts under a second every four, so the name is readable almost all of the time.

Cost. Per-letter fills, a few discs and short line runs from the clock, like the existing effects. Pixel is the odd one: in the game it would be drawn as a run of small squares on a grid rather than from a font, so it needs a tiny pixel-font table (about 60 glyphs). With Visual effects off each one is its still self.

Wiring (if picked). A row each in Rank.Cosmetics (kind NameEffect, after Rainbow so no existing number moves), a case each in DrawName, and a protocol bump for the larger lobby number. Ranks are not chosen yet. Every rank from 2 to 71 already has a reward, so new name effects would go above 71 or share a rank with something existing.
