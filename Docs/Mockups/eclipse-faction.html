The Penumbral Court

The Eclipse's faction, one enemy per Warden slot. Each previews one thing the Eclipse's five stages test, so its last ten waves rehearse the final fight in stage order: Corona, Penumbra, Umbra, Last Light, Totality.

Members

The Warden's slot each one fills is in brackets; the gold chip is the Eclipse stage it previews.

Campaign cycle

Waves 91–99, one lesson per wave, then the Eclipse at wave 100.
