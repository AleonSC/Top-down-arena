Piece layouts

Layouts for the bigger shapes, built from room-like cells (closets, vaults, halls and barracks with doorways, from cell layouts 13-18). Cells are open to each other; walls leave every cell middle (a chest can stand in any of them, faint squares) and every door lane open. Slots are fixed; each trap and loot slot still rolls.
