Piece layouts

Layouts for the bigger shapes (domino, three- and four-cell pieces). Cells are open to each other, so each layout is drawn for the whole piece; walls leave every cell middle (a chest can stand in any of them, faint squares) and every door lane open. Slots are fixed; each trap and loot slot still rolls. Approximate mockup, not the real draw code.
