Recording tab

Record / Stop, a link to the folder, and one row per replay: name, date, mode, class, wave reached, length, size. Open, Rename (inline, Enter to save) and Delete (asks first).

Playback

Opening a replay loads it into the game window with the wave-lane bar. Scrub, step frames, change speed, jump wave to wave.

Can the timeline alter a run?

Watching and scrubbing is solid: the file stores the match state every half second. Resuming play from any point (take over) is harder, because the game's random numbers are not seeded today and the saved state would need every timer, spawn queue and boss phase. I would ship watch and scrub first and add take over as a second pass.
