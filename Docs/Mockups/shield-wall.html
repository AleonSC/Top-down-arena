Shield Wall reworks

Today the Shield Wall is a pale arc with a bright rim. It appears, stops bullets, and vanishes, and nothing on it tells you how much it has left. Below are three reworks next to today's look, run against the three situations that matter (a regular volley, a boss wearing it down, the reflect capstone) at the game's real size and timing. The 120° arc, 4 s duration, 400 soak and every hit rule stay exactly as they are: this is drawing only. Each rework also uses the wall itself to show its remaining strength.

Build notes

  • All three reworks replace the two Arc(...) calls under if (p.WallT > 0f) in WorldPlayers.cs DrawKnight, plus a few effect spawns. No rule, number or hit test changes.
  • Hit flashes would hang off the existing blocked-shot branch in Juice.cs (the one that already spawns the sparks for a Shield Wall block), so the impact angle is already known on every client.
  • The wear display (cracks, dying cells, burning-out runes) needs the wall's remaining soak on the client. If it is not already replicated, a guess from blocked-hit events works for the mockup, but a real value means a snapshot change and a Session.ProtocolVersion bump.
  • Reflect (the mastered wall) keeps its meaning: the returned bolt leaves in the knight's colour, cyan.
