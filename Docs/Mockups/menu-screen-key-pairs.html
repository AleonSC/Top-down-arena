Main menu: screen + key pairs

The "Your runs" window pairs a green CRT screen with a physical key beside it: the screen says where you are, the key is the thing you press. Five ways to carry that onto the main menu buttons. Hover a key (or its screen) to see the pair light up; the screen cursor starts blinking. In look D the single screen follows the key you hover.
