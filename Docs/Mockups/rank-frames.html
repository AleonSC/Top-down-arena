Build notes

  • Drawing only. Every effect here is made of rects, lines, circles and the soft glow pills the party card already uses (DrawPartyCard in Game/LobbyUi.cs). Nothing is sent that isn't sent today: the lobby already carries each player's frame number (LobbyEntry.Frame), and each screen animates it itself from the clock, so everyone sees everyone's frame.
  • Frame style. Today Rank.FrameColor returns one colour per frame. These need a style as well as a colour, so I'd add a small FrameLook switch on the frame id (the same way TrailPiece switches on the trail id) and draw it from one helper that the party card, the results card, the cosmetics window and the Hangout name plate all call.
  • Protocol. New ids go in Rank.Cosmetics in rank order, which renumbers the frames in the lobby (Gold goes from 2 to 5, as Gold stardust did when the trails were added), so the protocol is bumped. Profiles keep ids, so nobody loses what they had equipped.
  • Hangout and small spots. The Hangout name plate and the cosmetics window thumbnails are too small for sparks and shimmers, so they use only the frame's base colour and a simple rim, as they do now.
  • Readability and cost. Effects stay inside a 14 px band round the card and never cover the portrait, name or Ready badge. Each frame is at most about 20 small shapes. With Visual effects off, every frame falls back to a static rim in its base colour.
  • My pick. Circuit (16), Ember Edge (20) and Void Pulse (24) first, because they fill the long gap between Steel and Gold and each needs only a few lines. Legend Foil (40) and Prism (50) are the rewards to chase. Say which you want and I'll build them with their README and tests.
