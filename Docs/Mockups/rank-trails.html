Build notes

  • Drawing only. Same mechanism as today: DrawRankTrails in Game/RankTrails.cs keeps each player's last 0.9 s of path (a point every 7 px) and draws from that. The lobby entry already carries each player's Trail index, so every player sees everyone's trail.
  • Protocol. New entries go at the end of Rank.Cosmetics (ids are stored in profiles and the lobby sends an index, so never reorder). The index is a byte on the wire, so no format change and no protocol bump is needed unless the table order changes for existing ones.
  • Ember and Gold are today's code unchanged. The four new ones are the same shape: one polyline of faded segments plus a few small particles per point, so cost stays near today's (about 15 points, up to 3 players).
  • Readability. Every trail is kept at low alpha and thin near the player so bullets and enemy telegraphs stay readable in a bullet hell. Prism is the busiest, which is why it's a Legend reward.
  • Colour clash. Frost and Void sit near some enemy and boss colours, so the trail is drawn behind the player and below projectiles.
  • Cosmetics UI. The Trail row in CosmeticsUi.cs already lists every trail with its rank. A small live preview in the row (this mockup's card canvas) is the natural follow-up.
  • Pick. I'd ship Frost (14), Storm (18) and Void (22) first because they extend the ladder through the Veteran and Champion tiers with the least new code, then Prism as the Legend flex. Say which you want and I'll build them, with their README and tests.
