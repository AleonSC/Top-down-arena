Lobby · Button styles, round two

One family of buttons

Round one made Back, Ready and Start three different colours and two different heights. Here all three are 52 px tall with the same corner, border and type. There is one hue, and state shows through the rim, a glow and a check mark: unselected, on (you're ready; Start can start), and dimmed (Start waiting). Each stage shows the left column in four moments: you're not ready, you're ready and others aren't, everyone's ready (host), and the same in Practice, where Start takes a teal tint.

Option 1

Slate blue, filled

Good: a solid version of today's blue. Same fill on all three, bright blue only when "on". The smallest step from the current look.Cost: still the heaviest, since filled buttons next to the panel are loud.

Option 2 · my pick

The lobby's own tiles

Good: reuses the dark glass, blue rim and underline of the Role / Class / Weapon tiles in the loadout, so the buttons read as part of the same screen and don't compete with it.Good: "on" is the same signal as a selected tile, so Ready behaves like picking an option.Cost: calmer, so Start needs the glow to stand out when it's ready.

Option 3

Ready and Start side by side

Good: two equal buttons in one row, the same blue, so they can't look like different sizes. Frees about 62 px of column height.Good: Back is the same blue, darker.Cost: shorter labels (Ready? / Start) and each button is 183 px wide.
