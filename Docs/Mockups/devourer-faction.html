The Devourer's Brood

Eight enemies, one per Warden enemy, so the lessons carry over. Brood are the living things it feeds on and spawns. Gut are pieces of the beast itself. Numbers are first guesses at wave 41. The sketches are approximate canvas drawings, not the game's draw code.

Notes

  • Tick mirrors the Security Guard (aimed single shot, strafe, reload). Gorger's mini inhale teaches the boss's Inhale.
