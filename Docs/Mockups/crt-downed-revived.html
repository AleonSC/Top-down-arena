DOWNED & REVIVED

Messages and digital animations for going down and getting back up, in the CRT look of the lobby and wave banners. Every tube loops the same story: a hit, down, an ally revives you for 3 s, back online. Drag a slider to step through it.

MESSAGES What the downed player sees (A, B) and what their team sees (C). Each ends with the revived message.

ANIMATIONS The player sprite itself, built from pixels. Any of these pairs with any message above.

HOW IT WOULD FIT Nothing is wired into the game yet. These are mockups only.

NO NETWORK CHANGEThe snapshot already carries Downed and Revive per player (GameNet.cs), so this is client drawing only and the protocol version stays.
COLOURSRed is the existing CrtStyle.Danger. Mint is a new revive colour; the blue ink and cyan tags come from the current CRT palette.
REDUCED EFFECTSUse the toggle at the top: glitch slices, noise, shake and glow drop out, the messages and the ring stay. It follows the setting the CRT screens already have.
