DOWNED & REVIVED

Messages and digital animations for going down and getting back up, using the game's real player models, in the CRT look of the lobby and wave banners. Every tube loops the same story: a hit, down, an ally revives you for 3 s, back online. Drag a slider to step through it.

MESSAGES What the downed player sees (A, B) and what their team sees (C). Each ends with the revived message.

ANIMATIONS The game's real player models (Knight Tank, Summoner Healer, Ninja DPS), using only effects the game can draw. Any of these pairs with any message above.

HOW IT WOULD FIT Nothing is wired into the game yet. These are mockups only.

NO NETWORK CHANGEThe snapshot already carries Downed and Revive per player (GameNet.cs), so this is client drawing only and the protocol version stays.
COLOURSRed is the existing CrtStyle.Danger. Mint is a new revive colour; the blue ink and cyan tags come from the current CRT palette.
WHAT THE GAME CAN DRAWThe model code already has a tint mix (the hit flash, mWhite), an alpha (mAlpha) and a movable origin. Ghost copies, flecks, rings and lines are plain GL draws. The tear-and-static look across the whole screen needs a render-texture pass I couldn't find in the game; toggle SCREEN GLITCH off to see the in-game version without it.
REDUCED EFFECTSThe top toggle drops glitch, ghost copies, glow and flicker; the messages, flecks and ring stay.
