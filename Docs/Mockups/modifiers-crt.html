Modifiers, tidied

The current tab puts a wide OFF | ON slider and an LED on the left, so the eye has to jump across to the description. In all three layouts below the switch sits on the right as a key button, the same family as READY?, with a check mark and glow when it is on. Names and descriptions get a clean left edge and the tier is a thin colour tick. Everything is clickable: toggle keys, fold a group by clicking its heading, and try Turn all off. The Harder group is open here so you can see a full list.

OPTION A

Stacked list

Easiest to scan. Name over description, key hard right. Cost: two lines per row, so fewer fit before scrolling. Closest to the current tab.

OPTION B

Aligned columns

Densest. One line per row; name column and description column line up like a readout. Cost: long descriptions wrap to two lines; needs the wide panel.

OPTION C

Tile grid

Biggest targets. Each modifier is its own card with a full-width key; reads like picking cartridges. Cost: taller overall, scrolls sooner; two columns need the full panel width.
