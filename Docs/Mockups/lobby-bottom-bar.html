Placing Back, Ready & Start

Measured from your screenshot. Today the 88 px bar has Back far left and a Ready? + Start pair floating mid-screen: they line up with nothing above them, the two look equally important (a greyed Start reads as a second Ready), and the "Waiting for N players" note is small, grey and far from what it describes. The party column also ends at y 460 and leaves ~150 px empty. Four takes below, all using the existing Ready (blue, then gold) and Start (blue, practice-tinted) colours.

Option A

Dock right, aligned to the loadout panel

Good: the smallest change: same bar, same buttons; the pair's right edge lines up with the panel edge (x 1240) and Start is the corner "finish" button.Good: the status note sits next to the buttons with ready dots.Cost: left side of the bar is mostly empty.

Option B · my pick

One button that changes with the situation

Good: one big centre button under the panel; no disabled Start sitting there. Guests see Ready? → Ready!; the host sees Ready? → Ready! → Start the moment everyone is in.Good: unready is a small link, so a misclick can't un-ready you.Cost: a behaviour change for the host: Start isn't visible until everyone's ready (the note says who's missing).
