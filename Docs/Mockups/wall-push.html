Room features

Each new section rolls one feature (seeded). Pieces build in 2 rows behind the face, so the spot you're pushing stays clear and a divider grows a tile per push.

This mockup's rules

  • Selection snaps to one straight face, 2–10 tiles.
  • After a push the selection rides the new face, so you can keep clicking.
  • Reach is 7 tiles: walk into the new space to push further.
  • Max 12 tiles out; stays 1 tile off other rooms and the map edge.
  • Features need 4+ wide (Baffles, Divider 5+; Pincers 6+). They never close the lane.
