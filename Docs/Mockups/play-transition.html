Notes for building it

  • One menuPlayT value (0 to 1) moves toward 1 on Play and back to 0 on Back or Esc, using unscaled time. DrawMenuCardInside draws both views while it is between 0 and 1 and passes live = false for the one on its way out, so nothing underneath is clickable during the move.
  • No network or save format change, so the protocol version stays the same.
  • Clicks are ignored until the move is at least 80% done, so a double-click cannot press Continue by accident.
  • The Esc and Back buttons run the same move in reverse, so look and timing stay one setting.
