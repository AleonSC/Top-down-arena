Katana sounds

Sound effects for the whole moveset: the chain, the meter, the Alt strike and the streak. Three sets of the same sounds, so you can pick a character. They are built in this page from the same pieces the game's SoundBank uses, and each card shows the recipe that would go into it.

Putting them in the game

  • One new Sfx value per sound, added at the end of the enum (before the other end-of-list groups), each with a Set(...) line in SoundBank.Build(). Names are in the recipe boxes.
  • Two small helpers join the existing ones: Delay (shift a layer later) and Room (the existing Reverb mixed back in at a set amount).
  • The chain, hit, lunge and Alt strike sounds are raised by the host through the existing fx path (BroadcastFx already takes an Sfx), so everyone hears them, quieter with distance as other swings are. The aim, switch, no-charge and meter cues play on your own screen only, like the pick and menu sounds, and are never sent.
  • The Katana's existing SwingLight and SwingHeavy are replaced for the Katana only.
