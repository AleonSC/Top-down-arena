# Map Sketch

Single-file iPad/Apple Pencil map sketcher in the game's neon-vector look (`index.html`, no build, no Unity).
Host the folder on any static HTTPS host (e.g. GitHub Pages), open in iPad Safari, Share > Add to Home Screen.
Pencil draws, one finger pans, two fingers pinch-zoom (Finger switch: finger draws too). Tools: Pen, Line, Room, Circle,
Pillar, Gate, Spawn, Text, Size (type exact W x H for a box, circle or pillar, or add a box of that size), Erase; 8 boss wall inks; snap/fill/grid; undo/redo; autosaves; PNG and JSON export (share sheet).
