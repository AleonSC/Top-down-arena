# Map Sketch

Single-file iPad/Apple Pencil map sketcher in the game's neon-vector look (`index.html`, no build, no Unity).
Host the folder on any static HTTPS host (e.g. GitHub Pages), open in iPad Safari, Share > Add to Home Screen.
Pencil draws, one finger pans, two fingers pinch-zoom (Finger switch: finger draws too). Tools: Pen, Line, Room, Circle,
Pillar, Gate, Spawn, Text, Piece (the game's grid pieces: Single, Domino, Line of 3, Corner, Line of 4, Square, T, S, L, plus the 4 x 3 Core; a cell is 6 x 6 tiles, snapped to the game's 600 px lattice; Rotate/Mirror or R/M, also on a selected piece; one rim round the whole piece), Edit (drag any shape to move it, arrows nudge one tile; type exact W x H in tiles of 100 px, the game's room unit; flags sizes outside the game's limits of 2-24 tiles a side and 144 tiles of floor; or add a box of that size), Erase; 8 boss wall inks; snap/fill/grid; undo/redo; autosaves; Main room button (the game's 16 x 9 tile hub, one per map); PNG and JSON export (share sheet).
