Reference WAV

Pick a Game sound (the names are the game's Sfx list) and export. Put the WAV in the game's sounds folder (persistentDataPath/sounds, read at startup) or in Assets/Resources/Sfx to ship it. It replaces that sound and keeps its volume slider. Takes: ShotRifle_1.wav, ShotRifle_2.wav... are played in turn; Takes to export makes that many, each with a small random pitch change (Variation) and new noise. Volume sets how loud the file is; Listen only sets how loud it plays here. The reference loads any WAV (for example one from Tools/SoundCheck/render.sh) to compare by ear.
